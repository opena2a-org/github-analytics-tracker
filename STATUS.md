# Status: experimental

**Stage:** experimental
**Maintenance horizon:** maintained on a best-effort basis through 2026-12-31, status reviewed quarterly
**Maintainer wanted:** no

## Stage rationale

github-analytics-tracker is an internal analytics dashboard used to preserve GitHub traffic beyond the 14-day retention limit. It's deployed for the OpenA2A org but is not currently positioned as a general-purpose product. API surface and data schema may change.

## Stage definitions

- **stable**: production-ready, semver honored, breaking changes documented, security patches triaged within 24 hours.
- **beta**: feature-complete or near, breaking changes possible with notice, actively developed.
- **experimental**: early stage, breaking changes expected, use at your own risk.
- **reference-only**: spec or reference implementation, not intended for production use.
